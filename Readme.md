# Attendiva

## Smart Attendance. Verified Presence.

Attendiva is a Windows desktop attendance management application.

### Features

- Employee Attendance
- Check-in / Check-out
- Leave Management
- Shift Management
- Overtime Management
- Rest Management
- Employee Bio Data
- Employee ID Card
- Payslip Management
- Attendance Authorization
- Attendance Reports
- Excel Export

### System Requirements

- Windows 10
- Windows 11
